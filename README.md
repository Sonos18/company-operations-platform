# Company Operations Platform

Prototype tương tác của nền tảng quản trị vận hành đa công ty. Cấu hình đầu tiên dành cho Việt Quốc Huy.

## Runtime

- Node.js 24.x
- pnpm 10.29.3

## Lệnh phát triển

```bash
pnpm install
pnpm dev
pnpm test:unit
pnpm test:e2e
pnpm typecheck
pnpm lint
pnpm build
```

Prototype chỉ dùng dữ liệu giả cục bộ. Không nhập hồ sơ, hợp đồng, ảnh hoặc bản vẽ thật.
